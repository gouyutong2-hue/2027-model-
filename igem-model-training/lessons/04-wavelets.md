# 小波｜在植物电信号中区分噪声与突变

**课时** 40 分钟。你将定位一个时间信号里的突变，并检验去噪有没有把突变一起抹掉。

## 原理与适用情景

Haar 小波把两个相邻的数变成一个低频近似 $(a+b)/\sqrt{2}$ 和一个局部细节 $(a-b)/\sqrt{2}$。对近似部分继续做同样运算，就会获得跨更宽时间尺度的细节。如果原始记录是等间隔采样，采样率决定每一级的时间尺度。阈值去噪把很小的细节压到 0，保留较大的系数，再把所有层重建回时间域。用于查异常时，需要单独定义打分和报告的位置。

讲义提到幅度突变和斜率突变。幅度跳变可先用两侧局部均值的差。斜率突变可比较两侧局部斜率，或在多个尺度用对局部线性趋势更不敏感的小波。db4、db6 的选用是经验方向。边界条件、采样率、噪声类型和针对信号的验证共同影响选择。

## 原研究怎么做

**Qiu 等，2026** 研究君子兰叶面电位，比较叶片不同位置对受控盐处理的识别效果。作者读取低幅非平稳电信号，先做小波阈值去噪，再逐时间窗作 min–max 归一化，随后用轻量网络做条件分类。Fig. 8–9 展示原始波形示例和去噪流程。原始录波据 Data Availability 需向作者索取。研究只有三盆植物，窗口中包含同株重复。评价新植物时需要按植株分组留出。§3.6 写出预处理顺序，所用小波族与完整门槛参数未在该节找到。[原论文 §3.6–3.7、Figures 8–9](https://pmc.ncbi.nlm.nih.gov/articles/PMC13164852/)

## 跟做

```bash
python examples/wavelets.py
python examples/wavelets.py --noise 0.5 --seed 2050 --output build/wavelets_noisier
```

1. [代码](../examples/wavelets.py) 生成 512 个等距采样点。正弦是背景，序号 237 加一个已知阶跃，之后加可复现的白噪声。单位为模拟信号任意单位。
2. 先把原信号分解四层再无损重建，程序断言检查重建。随后用最高频细节的中位绝对偏差估噪声，再用软阈值重建。默认原始 RMSE 约 0.267，去噪后约 0.103。
3. 定位使用可移动的 Haar 差分。每个候选位置向前后各取 12 点，两侧均值的差形成得分。默认找到第 237 点。打开 `build/wavelets/wavelets.png` 比较去噪波形与定位依据。真实数据要先估背景，再校准“多大分才算异常”。
4. 原论文还训练网络。课堂复现预处理思路并加入突变定位，使用 NumPy、Matplotlib，本机 CPU 即可。比较论文网络效果需要作者的数据、窗切分与训练细节，再按植株或日期验证。

## 评价与课堂题

小波适合局部、跨尺度的变化。已知主要干扰是固定频率时，先试频率滤波并检查相位与边缘失真。检测持续的均值变化时，可比较变点检测或已知跳变模板。对于波形分类，同株邻近窗口相似，随机拆窗口会让验证集过于容易。预处理须和数据划分及评价一起设计。

**课堂题** 改成两个靠近的阶跃，再把滑窗半宽从 12 改 6、24。记录检测误差以及是否还能分出两次变化。把阶跃改成分段直线，观察均值差打分怎样变。
