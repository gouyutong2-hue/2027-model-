# 蒙特卡洛｜光源能覆盖多大的搜索区

**课时** 35 分钟。输入是随机抽样的位置，输出是超过亮度阈值的面积比例。读完能复现抽样逻辑，并分清抽样误差和模型的不确定性。

## 原理与适用情景

把要计算的量写成随机变量的平均值。面积问题可以这样转化。在区域内均匀抽点，把能看见的位置记为 1，其余记为 0，平均值就是覆盖率估计 $\hat p$。独立抽样下，标准误约为 $\sqrt{\hat p(1-\hat p)/N}$。样本增加到四倍，抽样误差通常约减半。

同样的思路可以求积分、传播参数不确定性、比较随机情景。抽位置回答的是“这个区域有多大比例超过阈值”。抽亮度和天气则回答“不同情景下覆盖率会怎么变”。记录随机种子、算法和软件版本。需要独立重复时，派生多个随机流。

## 原项目怎么做

iGEM **NMU-China 2024** 把生物发光设计接到海上搜救情景。作者先用发光模型生成随时间变化的亮度，用高斯空间分布近似海面光照，再在每个时刻向搜索区抽取很多位置，按阈值判断是否有机会被看见。最后比较有无装置的模拟情景。原页面列出 Python、MATLAB 和脚本附录。Fig. 13 的百分比依赖其情景假设。光照达标与人员获救之间还隔着观测、航线、海况、搜索次数等环节。见 Model 小节 e–f、Fig. 12–13 与 Appendix。[原 iGEM Model](https://2024.igem.wiki/nmu-china/model)

## 本机复现

练习固定某一时刻，把光源当作通用点光源。方形边长 100 m，取教学参数峰值 0.8 µlx、特征扩散长度 18 m、阈值 0.2 µlx。平方距离为 $r^2=x^2+y^2$，亮度为 $I_0\exp(-r^2/2s^2)$。这组数字用于复现计算步骤。一次模拟只需要 CPU。

```bash
python examples/monte_carlo.py
python examples/monte_carlo.py --samples 40000 --seed 2041 --output build/monte_carlo_more
```

1. 读 [estimate_visibility](../examples/monte_carlo.py)。两列随机数分别是 $x$、$y$。用 `light >= threshold` 得到布尔数组，求均值就是命中率。
2. 默认阈值等高线是完全位于方形内的圆。解出 $r=s\sqrt{2\log(I_0/I_\mathrm{cut})}$，再算 $\pi r^2/100^2$，作为程序的独立检查。
3. 默认输出 `build/monte_carlo/coverage.png` 和 `visibility.csv`。实测抽样覆盖率 0.2859，Wilson 95% 区间约 [0.2771, 0.2948]，解析值约 0.2822。这个区间量化的是有限抽点的误差，使用不同种子得到略不同的数。
4. 增大 `--spread-m` 让阈值圆跨出方形。普通圆面积公式此时失效，抽样仍可以估算方形内部的覆盖比例。进一步可对亮度和天气分布各抽一层，报告情景间变化。

## 方法评价与课堂题

蒙特卡洛适合复杂地图、事件顺序和非线性模型。已知规则几何时优先用解析式当真值，低维光滑积分可用确定性求积。当损失集中在稀有事件，可比较分层采样、重要性采样或准蒙特卡洛，同时记录误差估计方法。[SciPy 准蒙特卡洛文档](https://docs.scipy.org/doc/scipy/reference/stats.qmc.html)

**课堂题** 保持随机种子，分别用 1000、4000、16000 个点运行。看区间宽度是否近似按 $1/\sqrt{N}$ 缩小。解释即使把 $N$ 再翻十倍，为什么仍无法弥补光分布函数写错。
