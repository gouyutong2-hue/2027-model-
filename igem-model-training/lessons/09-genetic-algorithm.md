# 遗传算法｜搜索一个有限电量的光源照明方案

**课时** 45 分钟。你会从真实 iGEM 优化流程抽出编码、评分、选择、交叉、变异五步，用同一评估预算比较遗传算法和随机搜索。

## 原理与使用

先把一个候选方案编码，例如一个 0/1 数组。为每个方案计算适应度。算法在多条候选中倾向于留下得分好的方案，再交叉组合它们的不同片段，随机变异其中的某些位置。重复到评估预算用完。锦标赛选择从若干随机候选中取当前分数最高的一个。轮盘赌选择按非负权重分配抽中的机会。精英保留让每轮最优分数保持不下降。适应度停在平台仍可能只是搜索停滞。

## 原项目怎么做

**NMU-China 2024** 希望提高搜救发光装置的模型输出。作者先建立随时间变化的发光与光照模型，进行敏感性比较，再用遗传算法搜索。可考的顺序是明确亮度目标、在候选参数上模拟、按适应度筛选并变异、比较优化前后的模型输出。作者使用 Python 的 DEAP，给出收敛图 Fig. 15、输出对照 Fig. 16 和脚本附录入口。报告的改善来自模型情景，验证改善需要独立观测。这个演示重建 GA 的决策步骤。作者的搜救模拟对应[蒙特卡洛一课](02-monte-carlo.md)。[原 iGEM Model 小节 g、Fig. 14–16 与 Appendix](https://2024.igem.wiki/nmu-china/model) · [DEAP 文档](https://deap.readthedocs.io/en/master/)

## 跟做

模拟的通用光源有 12 个时段，每个时段亮度档位记为 0 或 1，最多开 5 次。时段的重要性用脚本中的整数权重表示，相邻时段连续开启有额外损失。用人工设定的目标函数充当仪器设计评分，数值没有物理单位。原作者采用 DEAP，课程脚本只用 NumPy 和 Matplotlib，运行在 CPU 上。

```bash
python examples/genetic_algorithm.py
python examples/genetic_algorithm.py --seed 2088 --output build/ga_second_seed
```

1. [代码](../examples/genetic_algorithm.py) 的 `fitness` 用时段权重和减去连续开启的惩罚，给超额开启的解负分。先用两条手工方案验证评分。
2. 初始化 24 条随机候选，做锦标赛选择、单点交叉和位翻转变异。每代保留一个当前最优。预算 24 代，共 576 次适应度评估。
3. 在同样的 576 次评估预算内，用均匀随机候选做对照。另枚举全部 $2^{12}$ 种方案求这个小问题的真最优值 17。
4. 比较 20 组随机种子。默认本机测试中 GA 到达最优 20 次、随机搜索 10 次。打开 `build/genetic_algorithm/search.png` 看中位进展与四分位范围。更换种子或任务后要重新报告这些比例。

## 评价与课堂题

GA 仍适合组合空间大、结构不规则、一次评分能模拟但难求梯度的问题。小问题先穷举拿真值。这个二值示例可为连续开启新增 0/1 变量并用 MILP 求有证书的最优解。连续黑箱、每次仿真很贵时可测试贝叶斯优化。光滑且有导数时试梯度类方法。选择依据是结构、评分预算和是否需要最优性证明。

**课堂题** 把连续开启惩罚由 3 改成 0，再把它改成 8。每次预测最优方案更偏向集中还是分散，运行验证。增加种群或代数后，与随机基线对比时保持总评估次数相同。
