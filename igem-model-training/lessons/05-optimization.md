# 线性规划、整数规划和非线性规划｜把目标与约束写成模型

**课时** 60–75 分钟。完成三次求解，分别找磷储存通量上限、手术间最小最大工作量和生长曲线的拟合参数。

## 原理与选择

| 方法 | 要解的问题 | 在这章的对应 |
|---|---|---|
| 线性规划 LP | 最小化 $c^\top x$，目标和约束都线性，变量可连续变化 | 稳态代谢网络的通量 |
| 混合整数线性规划 MILP | 目标、约束线性，部分变量只能取整数，0/1 可代表是否选择 | 手术能否分配到指定房间 |
| 非线性规划 NLP | 目标或约束依赖非线性函数，可以加边界和约束 | 从生长数据求曲线参数 |

在求解器中把最大化变成最小化时，目标系数加负号。先列决策变量、量纲、范围、等式和不等式，再写模型。运行后检查求解状态、约束残差、对边界和目标的敏感性。有多个同样好的解时，解释目标值与单个方案的区别。

## LP｜Düsseldorf 2023 Fungilyzer

团队考虑用酿酒酵母处理含磷问题。原项目从已发表的 iND750 网络出发，用计量矩阵和通量边界描述多反应系统，再讨论添加酶容量限制以及用实验把参数落到实际系统。给出的 Julia 示例使用 COBREXA、Gurobi、Distributions，示例中的部分酶动力学量为随机生成，加酶约束也需要额外输入。阅读时把作者的计划、示例与实验支持分开。该网页没有给出可供验收的实测磷吸收优化结果。[iGEM Model，Aim、Model structure、Understanding the code](https://2023.igem.wiki/duesseldorf/model/) · [iND750 原始建模论文](https://doi.org/10.1101/gr.2250904)

FBA 即通量平衡分析。反应以列表示，代谢物以行表示。矩阵 $S$ 存每个反应消耗或生成多少，决策变量 $v$ 存通量。稳态约束 $Sv=0$ 表示每种内部成分的净变化率为零。课上用 P 和 C 两个内部资源编一个最小网络。摄入上限来自设定，增长至少为 1，增长消耗 1 单位 P 和 2 单位 C，储存每单位 P 另耗半单位 C。目标是最大化 P 储存。教学通量使用一致的相对单位，和酵母实测通量无直接数值映射。

```bash
python examples/optimization.py
```

看 `build/optimization/phosphate_flux.csv`。P 摄入上限从 1 增到 6 时，最优储存依次是 0、1、2、3、4、4。为什么最后不增加？算一遍 C 守恒。脚本还允许从原团队使用的底层网络加载一个标准 BiGG JSON，求该模型的默认目标值。可在 [BiGG iND750 页面](https://bigg.ucsd.edu/models/iND750) 下载 JSON 到课程目录，再运行以下命令。

```bash
python examples/optimization.py --bigg-json iND750.json
```

这一步读取真实的代谢物、反应、上下界和默认目标，打印矩阵规模、最优值与最大守恒残差。本机实测 1059 个代谢物、1266 个反应，默认目标约 0.0973234，最大绝对守恒残差约 $7.6\times10^{-10}$。它实现底层网络的普通 FBA。原作者附加的酶约束示例属于后续分支。网络下载需要联网，数据文件保留在本机即可。课程的 SciPy/HiGHS 求解用本机 CPU；作者平台为 Julia 和商业求解器 Gurobi，网页未报告运行机器配置。[BiGG iND750 模型](https://bigg.ucsd.edu/models/iND750) · [SciPy linprog](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.linprog.html)

## MILP｜西班牙教学医院的手术排程

Pulido 等从托莱多医院泌尿外科手术清单获取估计时长，分别记录准备、主手术、清理，主手术时间随医生经验而变。作者把人员和房间分配、手术顺序、加班等写入 MILP，以手术室空置、医生等待和加班费用之和作为目标。AIMMS 3.14 建模、Gurobi 5.5 求解、Enterprise Dynamics 8.01 做离散事件对照。论文表 2 为时长，表 3 为测试日实例，表 4 与式 (1)–(18) 给出变量和完整模型。[论文 Methods、Tables 2–4](https://oa.upm.es/37982/1/INVE_MEM_2014_206002.pdf)

课堂从表 3 实例 2 的五个手术类型 E、E、D、F、G 出发。用表 2 的 $k=1$ 时长作为统一估计，准备、手术、清理相加得到 150、150、105、210、275 分钟。每个手术恰选一个房间，D 只能在第一个房间。每间的总用时上界是 $T$，目标使 $T$ 尽量小。代码用 `milp` 和小规模穷举独立对照，最优最大工作量 315 分钟，查看 `room_assignments.csv`。这个聚合模型只比较容量，不生成可供医院使用的医生班表。加入医生、准备阶段和时间重叠约束后，最优结果可能改变。用本机 CPU 即可跑课程问题。[SciPy milp](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.milp.html)

## NLP｜非线性生长曲线

实测对应是[Fudan 的酵母生长案例](13-differential-equations.md)。本章 `logistic_nonlinear_fit` 单独展示求解器步骤。给出 $K,r,X_0$ 三个初值和边界，把 Logistic 预测减去教学模拟数据得到残差向量，由 `least_squares` 调整参数。默认估计约为 $K=1.2930$、$r=0.3023\ \mathrm{h}^{-1}$、$X_0=0.0494$。运行只用 CPU。残差要先定义清楚。观测方差变化时，应解释权重。只有早期时间点时，数据通常对上限 $K$ 缺乏约束。[SciPy least_squares](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.least_squares.html)

## 评价与课堂题

LP 和 MILP 仍是这类问题的基础工具。稳态及目标有生物学依据时，LP 可以给出清晰的可行上限。替代最优解可用 FVA 查看保持目标值时单条通量的可行范围。需要浓度随时间变化时，可考虑动态 FBA 或显式动力学。排班约束若大量涉及顺序和时段，可比较约束规划或 CP-SAT。有明确可微残差时优先用结构化的最小二乘。复杂非凸目标可跨初值试验并做基线比较。随机搜索提供候选解，通常没有全局最优证明。

**课堂题** 把模型的 C 摄入上限从 4 降到 3，算出储存通量何时见顶，再运行验证。接着给排程增加一个只能进第一个房间的 100 分钟任务，比较最优工作量的变化。
