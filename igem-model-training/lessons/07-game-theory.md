# 07 博弈论｜相互影响的策略怎么建模

**对应讲义** 《数学建模算法.html》第 6 节与《第七章 对策论》§1–5（讲义印刷页 154–166）。预计 90–120 分钟。

读完能从行为和观测定义收益矩阵，分辨纯策略和混合策略，知道什么时候用线性规划。再用酵母的生长数据检验一个关于合作的机制假设。

## 1. 把双方、策略和收益写出来

| 方法 | 问题 | 本章对应案例 |
|---|---|---|
| 零和与常数和、纯策略与鞍点 | 一方收益等于另一方损失，或两者之和固定 | 捕食者和猎物的短时搜寻，收益为捕获概率及其补值 |
| 混合策略、极大极小与线性规划 | 双方各自在可选策略间随机化，计算对方最不利反应下的可保证水平 | 用 SciPy 求双方策略和博弈值 |
| 双矩阵、纯策略与混合 Nash 均衡 | 各方分别最大化自己的收益，找到谁都无法单方面改善的策略组合 | 教学雪堆矩阵与原论文的酵母频率依赖模型 |
| 演化博弈与复制子方程 | 不同类型在群体中按生长优势改变频率 | 复现酵母合作与搭便车的共存条件 |
| 合作博弈与 Shapley 值 | 合作成员或变量如何分到对输出的贡献 | iGEM CJUH-JLU-China 的模型解释与教学小算例 |

先问三个问题。谁能改变行为？每位参与者到底能选择什么？“更好”能否用模型里可计算、可验证的量表达？动物搜寻例中的收益是捕获概率，微生物演化例中是频率依赖的生长收益，特征归因例中的“参与者”则是输入变量。三个问题的结果分别是策略分布、群体组成和模型解释。

## 2. 零和案例｜搜寻两个栖息点

Alpern 等 2019 年用低密度动物的短时搜寻问题研究捕食者与猎物的相互策略。作者把一次搜寻的可选地点、捕食者一轮可搜的地点数、发现后成功捕获的概率写进博弈。在多轮模型中，猎物逃脱后进入新的状态，转移地点有额外风险。论文 §6 对比只优化捕食者的 MDP、无转移风险的重复对策以及有风险的随机对策。数值输入是论文构造的示例，可用它核验算法。[原论文 §4–6、表 3](https://wrap.warwick.ac.uk/id/eprint/114627/)

先取 §6 的两处地点。发现猎物后，地点 1 和地点 2 的捕获概率分别为 0.1、0.8，一轮只能搜一处。行代表捕食者搜哪里，列代表猎物躲哪里。两者在不同地点时，捕食者收益为 0，所以矩阵是

$$
A=\begin{pmatrix}0.1 & 0\\0&0.8\end{pmatrix}.
$$

1. **纯策略**。对每行取最小值，再取较大值，给出捕食者固定策略能保证的下界 0。对每列取最大值，再取较小值，给出猎物固定策略能保证的上界 0.1。上下界相同且在一个格子对应时就是鞍点。这个矩阵需要考虑混合策略。
2. **混合策略**。令捕食者搜地点 1 的概率是 $p$，两列期望收益是 $0.1p$ 与 $0.8(1-p)$。两者相等于 $p=8/9$，此时捕获概率 $0.0889$。猎物也以 $8/9$ 的概率选择地点 1。把猎物收益写成 $1-A$ 就是常数和，减去常数 1 后可直接用零和算法。
3. **扩展到大矩阵**。令 $x$ 为行策略的概率向量，最大化保底收益 $v$，约束 $A^\top x\ge v\mathbf 1$、$\sum x=1$、$x\ge0$。列玩家最小化上界。脚本分别算两方，检查最坏列和最坏行的值一致。纸笔手算这一步与线性规划应给出一致结果。
4. **扩展到多轮**。先令逃脱后的最终捕获概率为 0。每轮对每种“上次逃脱的位置”构造一个矩阵，收益加上转移风险及找到猎物后延续游戏的期望，解当前零和矩阵并更新状态的值，直到相邻两次计算的差小于容差。最后从初始状态再解一次。在无转移风险时得到 0.2205（论文约 0.22），风险 0.3 时得到 0.2977（论文约 0.29），后者两个逃脱状态分别得到 0.3857、0.4536（论文约 0.39、0.45）。[论文公式 6.1–6.13 与表 3](https://royalsocietypublishing.org/doi/pdf/10.1098/rsif.2019.0087)

建模影响来自“双方会互相调整”。若假设猎物每轮等概率选位置，捕食者单方优化，论文会得到更高的捕获概率。这种对照揭示假设如何影响结论。单个动物的运动轨迹、空间密度与学习规则需要另外的数据和模型。论文给出数值方法，公开材料中未定位到软件版本与原作者脚本。本章用 SciPy HiGHS 与自编的值迭代，普通 CPU 可运行。[SciPy 线性规划文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.linprog.html)

## 3. 非零和案例｜酵母为什么能和搭便车者共存

Gore、Youk 与 van Oudenaarden 研究酿酒酵母中一种公共资源问题。合作型付出生产成本，产生的糖可以被周围细胞利用。未付出该成本的类型也能利用公共糖。作者从以下三个证据环节建立模型。[Nature 原论文](https://doi.org/10.1038/nature07921) · [作者实验室全文，图 1–3](https://www.youklab.org/papers/Nature2009_GoreAndYouk.pdf)

1. 用不同初始频率的混合群体跟踪合作比例。合作型稀少时上升，搭便车型稀少时也能上升，因而模型需要解释“双向入侵”。
2. 把生长收益拆为可独享和可共享的部分，再扣除合作成本。作者估计私有捕获比例 $\varepsilon\approx0.01$。线性收益下，合作型比搭便车型总是多 $\varepsilon-c$，内点稳定共存缺少来源。
3. 用糖量与生长率的观测约束收益函数。图 2 采用凹的幂函数，指数为 $\alpha=0.15$，作者报告估计为 $0.15\pm0.01$。令当前合作频率为 $f$，共享收益对应的输入为 $s=(1-\varepsilon)f$，则图 2 模型可写为 $P_C=(s+\varepsilon)^\alpha-c$ 和 $P_D=s^\alpha$。只需检查差 $\Delta=P_C-P_D$。若 $\Delta(0)>0$ 且 $\Delta(1)<0$，合作稀少时占优、常见时吃亏，解释了两种类型为何能够共存。

### 从双矩阵过渡到群体频率

先看讲义的有限策略模型。例子的行收益矩阵为 $[[3,1],[4,0]]$，列收益是其转置。面对合作时搭便车收益 4 比合作 3 高，面对搭便车时合作收益 1 比另一种的 0 高。检查双方最佳反应，可得两个不对称纯 Nash 均衡 $(C,D)$ 与 $(D,C)$。若对手以概率 $q$ 选 C，C、D 的期望收益为 $1+2q$ 与 $4q$，相等时 $q=1/2$。双方都采用该概率也构成一个均衡。该数值矩阵是课堂输入。

然后把策略换成群体频率。教学代码用复制子方程 $\dot f=f(1-f)\Delta(f)$ 表达相对生长优势。对于 $\alpha=0.15$，在所选参数范围内 $\Delta$ 随 $f$ 下降，因此内点根稳定。示例用原论文指数和近似私有比例，取教学成本 $c=0.02$，复算稳定合作比例约 **0.0431**，线性模型同参数最终趋于 0。作图的时间是模型时间，实验图 1 的不同处理条件和按天时间序列需另行校准。作者论文给出实验读数和模型结构，公开正文未定位到原软件、完整逐点数据和模拟脚本。

## 4. iGEM 案例｜用合作博弈解释生物信息模型

CJUH-JLU-China 2023 的 Wiki 把两个表达数据源的差异分析与 ROC、随机森林、SHAP 组织成候选特征评估流程。队伍先比较候选表达特征，再将样本标签用作训练目标，把 miRNA 作为随机森林的输入变量。Wiki 记录了 8:2 的训练／测试划分、网格搜索与五折交叉验证，以及图 7 的 SHAP 排名。重建图 7 还需要样本划分、随机种子、背景选择和解释器配置，页面公开叙述未给出这些要素的完整规格。[CJUH-JLU-China Bioinformatics Analysis，Feature Importance，图 6–7](https://2023.igem.wiki/cjuh-jlu-china/bioinfo)

教学脚本给出一个可手算的两变量预测器。把每个特征视作一个“参与者”。对固定样本，未加入的变量先由两条背景样本填充。变量在不同加入顺序中的增量不同，对两种顺序取平均，得到两个 Shapley 值。检查式为 **背景预测 0.20 + 第一变量贡献 0.20 + 第二变量贡献 0.30 = 样本预测 0.70**。这一步可以理解原 Wiki 为什么把贡献画成条形图。实际报告全局重要性时可明确采用哪个汇总量，比如对独立测试样本的绝对 SHAP 值求均值。结果依赖预测模型和背景，检验联系的生物意义还要独立证据。[Lundberg 与 Lee，SHAP 原论文](https://proceedings.neurips.cc/paper_files/paper/2017/hash/8a20a8621978632d76c43dfd28b67767-Abstract.html)

## 5. 本机复现与验收

软件用 Python、NumPy、SciPy 和 Matplotlib。求解小矩阵、ODE 和两变量 SHAP 均适合本地 CPU。

```bash
python examples/game_theory.py
```

[示例源码](../examples/game_theory.py)

程序输出矩阵策略、博弈值、酵母平衡点和特征贡献。打开 `build/game-theory/yeast_game.png`，左图把图 2 方程的线性边界和非线性三个区域画出来。右图从四个不同初始点出发，轨迹应朝同一条平衡虚线走。

- 把单轮矩阵的右上角从 0 改为 0.2，重新算纯策略的上下界。两者应同为 0.1。手查鞍点是否在左上角。
- 用 $f=0$ 和 $f=1$ 手算非线性收益差的符号，再把 $c$ 设为 0.55。解释条件跨过哪条边界。
- 改变教学 SHAP 的背景样本。记录基准和两项贡献如何变动，检查三项的和是否仍等于样本预测。
- 简单零和模型和 Nash 概念仍适合可定义策略集、收益和比较条件的场景。空间位置、总群体数量或资源消耗会反过来影响收益时，可采用空间个体模型或把资源动力学和演化方程耦合。原始研究也有先用多主体生态模型估计相遇频率，再计算收益矩阵与 Nash 均衡的做法。[PLOS Computational Biology 的捕食与防御行为研究](https://journals.plos.org/ploscompbiol/article?id=10.1371%2Fjournal.pcbi.1013730)对特征重要性，若目标是独立测试集上的模型性能变化，可同时报告置换重要性并注明相关变量对解释的影响。
